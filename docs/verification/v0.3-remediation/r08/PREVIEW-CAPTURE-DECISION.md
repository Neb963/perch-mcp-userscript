# R08 — unsaved preview capture architecture decision (owner gate)

**Status:** `S07-023` FAIL; no qualifying userscript-only pixel capture was proven. This record changes no permissions, adds no extension and performs no capture. Full requirement: v0.3 implementation specification §7.1 and accepted revision-3 amendments.

Actual preview pixels must belong to the *currently unsaved* exact Generator, Draft, Target and PreviewRevision. Reconstructed DOM, canvas approximation, Manager screenshots and arbitrary active-tab/window captures are non-equivalent. A cross-origin iframe, scrolling, zoom, composition, screen selection and revision races can expose unrelated content or misattribute an image.

**Platform alternatives, checked 2026-11-28:** `navigator.mediaDevices.getDisplayMedia()` requires a user gesture and user-selected surface. It cannot silently or verifiably target this preview. Firefox's `browser.tabs.captureVisibleTab()` can return the actual visible active-tab pixels with an `activeTab` grant after explicit user interaction (Firefox 126+); this is a privileged WebExtension API, not a Violentmonkey GM API. References: [Firefox capture](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/tabs/captureVisibleTab), [activeTab grant](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/activeTab_permission), [display capture](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia).

**Smallest candidate, requiring explicit owner approval:** independent, audited Firefox companion with only `activeTab` and browser-action click-to-capture. Its trusted channel must bind nonce, installation, Connector, Target/Binding, exact Generator/Draft/PreviewRevision, selected tab ID and expiry. Validate authorized and visible preview, zoom/DPR/crop rectangle and revision before and after capturing; crop **inside** companion before any transmission, never store/transmit the full tab. Reject mismatch, partial overlay, unknown iframe geometry or changed preview. Enforce bounded image output, consent, cancellation cleanup and result-access ACL. `activeTab` proves an operator's chosen tab, **not** automatically the exact unsaved preview. Crop/subject attestation and revision fencing require genuine browser proof.

**Operator-only acceptance:** disposable generator, real Firefox/Violentmonkey, unsaved preview pixel comparison and identities; test stale revision, rebind/revoke, wrong active tab, cross-origin iframe, scroll/zoom/hidden or occluded preview, failed consent, timeout/restart, image-result interoperability and no unrelated-pixel leakage. If geometry/identity cannot be proven, leave tool returning `UNSUPPORTED_INTERFACE`. Do not install the companion, request permissions, deploy or merge without an explicit decision. Production completion is blocked even if offline tests otherwise pass.
